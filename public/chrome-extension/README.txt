====================================
Tok Factory 助手 v2.0
多线程下载加速 + 商品提取
====================================

【功能介绍】
1. 视频多线程下载加速 - 类似 IDM 的分片并行下载
2. 商品信息一键提取 - 从电商网站提取商品数据

【安装步骤】
1. 打开 Chrome 浏览器，访问 chrome://extensions/
2. 打开右上角的"开发者模式"
3. 点击"加载已解压的扩展程序"
4. 选择本文件夹（chrome-extension）
5. 安装成功后，工具栏会出现 Tok Factory 图标

【使用方法 - 视频下载加速】
1. 访问 Tok Factory 视频批量页面
2. 选择要下载的视频
3. 点击"下载选中" → "插件下载（最快⭐）"
4. 扩展会自动接管下载，使用多线程加速

【使用方法 - 商品提取】
1. 访问任意电商商品页面（淘宝/京东/拼多多等）
2. 点击 Tok Factory 扩展图标
3. 商品信息会自动提取并跳转到 Tok Factory

【下载速度设置】
- 点击扩展图标可以调整线程数
- 2线程：稳定，适合网络不稳定时
- 4线程：平衡（推荐）
- 8线程：最快，可能被限速

【常见问题】
Q: 为什么有些视频下载慢？
A: 可能是 CDN 不支持分片下载，会自动回退到普通下载

Q: 下载进度在哪里看？
A: 点击扩展图标可以看到下载队列和进度

【技术原理】
扩展使用 HTTP Range 请求实现分片下载：
1. 获取文件总大小
2. 将文件分成 N 个分片
3. N 个线程同时下载各个分片
4. 合并分片后保存文件

这与 IDM/迅雷 的多线程下载原理相同。
