TikTok Content Posting API

审核视频录制脚本

对照 Content Sharing Guidelines (Point 1-5) 设计 · 覆盖全部 15 项合规检查点

官方规范: https://developers.tiktok.com/doc/content-sharing-guidelines/

📋 录制前准备

1 进入发布页面 ~5秒
  1. 打开 https://www.toryxai.com/publish
  2. 停留 2 秒，展示页面标题、"创建发布 / 发布记录" 标签
审核员需看到 ✓ 正式产品页面，非测试环境
✓ 页面标题为 TikTok 发布功能
2 上传视频 + 展示 Preview Point 5a / 5b ~15秒
  1. 在 Step 1 点击添加视频（本地上传 或 从视频制作区选择）
  2. 等视频出现在已选列表
  3. 停留 3 秒，鼠标指向视频卡片
审核员需看到 ✓ 真实视频的缩略图 / 封面预览
✓ 视频文件名可见
✓ 视频内容无水印、无logo、无宣传文字
3 选择账号 + 展示 Creator Info Point 1a ~10秒
  1. Step 2 选择 TikTok 账号
  2. 滚动到 Step 3 顶部
  3. 停留 3 秒
审核员需看到 ✓ Creator 头像
✓ Creator 昵称（如 "Army Artisan"）
✓ @username（如 "@user93816092905303"）
4 Title 可编辑 + AI 辅助后用户可改 Point 2a / 5b ~12秒
  1. 手动输入标题（例如 Beautiful sunset view #nature）
  2. 停留 2 秒
  3. 点击 "✦ AI 写标题" 按钮
  4. AI 生成标题后，手动修改几个字（证明用户可编辑）
  5. 停留 2 秒
审核员需看到 ✓ Title 可手动输入
✓ AI 是辅助功能，不是强制
✓ 用户对标题有最终控制权
5 Privacy 无默认值 + 手动选择 Point 2b ~12秒
  1. 展示 "可见范围" 显示 "请选择可见范围"（无默认值）
  2. 展示红色提示 请选择可见范围后才能发布
  3. 停 2 秒
  4. 点击下拉框展开，停 3 秒 让审核员看到所有选项
  5. 选择 "公开 / Everyone"
审核员需看到 ✓ 没有预设默认隐私选项
✓ 用户必须手动从下拉框选择
✓ 选项来自 creator_info API 的 privacy_level_options
6 互动设置默认 OFF Point 2c ~8秒
  1. 停 2 秒 — 展示三个互动开关都是 OFF
  2. 可选：手动开启"允许评论"演示一下，再关回去
审核员需看到 ✓ 允许评论 — OFF
✓ 允许合拍 — OFF
✓ 允许引用 — OFF
✓ 全部默认关闭，用户可手动开启
7 商业内容披露默认 OFF Point 3a ~5秒
  1. 停 2 秒 — 展示 "商业内容披露" toggle 为 OFF 状态
审核员需看到 ✓ 商业内容披露默认关闭
8 披露 ON + 未选子项 → 发布禁用 Point 3a ~15秒
  1. 打开 toggle 为 ON
  2. 不勾选任何子项
  3. 停 3 秒 — 展示区块内提示：
You need to indicate if your content promotes yourself, a third party, or both.
  1. 滚动到页面底部
  2. 停 2 秒 — 展示发布按钮灰色不可点击 + 旁边提示：
Please select a disclosure type before publishing.
⚠ 关键段 — 审核员需看到 ✓ 披露开启但未选子项时，发布按钮被禁用
✓ 两处英文提示文字清晰可见
9 Your Brand Only → "Promotional content" Point 3a ~8秒
  1. 勾选 "自有品牌推广 (Promotional content)"
  2. 确保 "品牌合作内容" 未勾选
  3. 停 3 秒
审核员需看到 ✓ 标签提示：Your video will be labeled as 'Promotional content'
✓ 法律声明只显示 Music Usage Confirmation
10 Branded Content Only → "Paid partnership" Point 3a / 4 ~8秒
  1. 取消 "自有品牌推广"
  2. 勾选 "品牌合作内容 (Paid partnership)"
  3. 停 3 秒
审核员需看到 ✓ 标签提示：Your video will be labeled as 'Paid partnership'
✓ 法律声明变为 Branded Content Policy & Music Usage Confirmation
11 Both Selected → "Paid partnership" Point 3a / 4 ~8秒
  1. 再勾选 "自有品牌推广"（此时两个都选中）
  2. 停 3 秒
审核员需看到 ✓ 标签仍为：Your video will be labeled as 'Paid partnership'
✓ 法律声明仍为：Branded Content Policy & Music Usage Confirmation（双链接）
12 互锁 A：Branded Content → 仅自己被禁用 Point 3b ~10秒
  1. 保持 "品牌合作内容" 勾选
  2. 打开可见范围下拉框
  3. 停 3 秒
⚠ 关键段 — 审核员需看到 ✓ "仅自己" 选项灰掉 / 不可选
✓ 提示文字：Branded content visibility cannot be set to private.
  1. 关闭下拉框
13 互锁 B：先选仅自己 → Branded Content 被禁用 Point 3b ~10秒
  1. 先取消品牌合作内容勾选，关闭商业披露
  2. 可见范围选择 "仅自己"
  3. 重新打开商业内容披露
  4. 停 3 秒
⚠ 关键段 — 审核员需看到 ✓ "品牌合作内容" checkbox 灰掉不可点
✓ 提示：Branded content is not available when privacy is set to Only You
14 AI 生成内容标记（独立区块） ~5秒
  1. 滚动到 "AI 生成内容" 区块
  2. 停 2 秒
审核员需看到 ✓ AI 标记与商业披露是独立分开的区块
15 任务组名称 ~5秒
  1. 滚动到 "任务组名称（可选）"
  2. 输入一个名称（如 "Demo post"）
  3. 停 1 秒
16 恢复合法状态 + 创建任务 Point 5c ~10秒

为了成功发布，恢复到最安全的发布组合：

  1. 将可见范围改为 "仅自己"（最安全，不会意外公开测试视频）
  2. 关闭商业内容披露
  3. 确认：视频已选 ✓ 标题已填 ✓ 隐私已选 ✓
  4. Step 4 选择 "立即发布"
  5. 点击 "创建任务" 按钮
审核员需看到 ✓ 发布是用户主动点击后才发生，非自动上传
17 发布后提示 + 任务状态追踪 Point 5d / 5e ~10秒
  1. 页面自动跳转到 "发布记录" 标签
  2. 停 3 秒 — 展示任务卡片
  3. 展示状态标签（执行中 / 待处理）
  4. 展示底部提示文字：
发布后可能需要几分钟才能在 TikTok 显示
  1. 等待 10-20 秒，观察状态自动轮询变化（页面每 10 秒自动刷新）
  2. 点击任务卡片打开详情弹窗
  3. 停 3 秒 — 展示子任务状态（processing / uploading / published / failed）
  4. 结束录制
⚠ 关键段 — 审核员需看到 ✓ 发布后有处理时间提示
✓ 任务状态会自动更新（轮询）
✓ 用户可以了解发布进度
