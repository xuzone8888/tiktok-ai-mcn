## 〇、三句话结论

1. **画布流:不做通用无限画布**(画布独有增量 4.5–7.5 传统人月、付费用户画像与我方个体卖家客群基本错位、与 S5「把复杂度藏起来」的智能体化裁决反向);但**「固定拓扑可编辑管线视图」值得做**——它是 S5 v1 导演脚本确认与 v2 镜级重roll 的天然交互宿主(2–3 周量级,条件=S5 v1 落库后),且「不做画布」判决配 4 条复评触发器,是有半衰期的裁决而非永久信条。
2. **外贸 SaaS:不「转型」,做「先证后投的外贸楔子」**——外贸方向的「AI 视频×爆款拆解×多平台官方 API×批量工厂」四要素交集确为无人占据(国内 9 家+海外 11 家实调交叉证实),但付费锚(询盘≠内容)、销售驱动渠道、单人 SaaS 成功模板三项逆风同样坐实;90 天内外贸只做近零代码验证(配方包+en 出片+wa.me 短链+3 家种子),同时并行「国际化探针」(英文 landing+美元定价调研),120 天带数据选边。
3. **S5 出片质量主线一个字不改**(四路对抗全部攻不动:B2B 内容对可信度要求更高,质量线是所有分支下的无悔投入);**Adapter 并行线提级先行**(teammate 分支又克隆了 LinkedIn 5 张表——「再接平台=再复制 5 表」的预警第五次应验,该理由独立于外贸决策成立)。

## 一、课题一:画布流复刻评估

### 1.1 liblib.tv 实访:它到底是什么

**liblib.tv = LibTV**,LiblibAI(哩布哩布)2026-03-20 推出的独立 AI 视频创作平台,自称「全球首个同时面向人类创作者与 AI Agent 的专业视频创作平台」——**不是**其模型社区主站(liblib.art)。官网实抓+多源交叉核实:

- **交互范式:确为无限画布+节点连线**。文本/图片/视频/音频/脚本五种基础节点自由连线;剧本→分镜→图片→视频→成片全程在一块无限画布上;工作流可保存复用、画布可分享、可发布到社区(但未见 liblib.art 式的独立工作流交易市场)。
- **本质是模型聚合器+价格屠夫**:聚合 20+ 视频模型(可灵 3.0/O3、Wan 2.6、Seedance 1.5/2.0 满血 4K、Hailuo、Vidu 等),年卡 499–6,599 元四档,「会员 SKU 较竞品低 76%、模型积分低至竞品 8%」,实测 30 秒短剧折合几块钱一条(来源:量子位/网易/ai-bot 交叉)。
- **Agent 原生入口**:GitHub 开源 `libtv-labs/libtv-skills`(MIT,816 stars,`npx skills add` + ACCESS_KEY),Agent 可一句话生成 5 分钟短剧、复刻参考视频、URL 生成产品展示片。
- **规模与弹药**:上线首日 10 万创作者涌入;一个月签 300+ 家短剧公司 B 端团队;月收入百万美元级(网易「单日百万美金」与腾讯新闻「单月百万美金」口径相差 30 倍,取后者为可信下限);母体 LiblibAI 2,500 万用户、2025-10 B 轮 1.3 亿美元(红杉/CMC),另有中文财经媒体口径 ARR $3 亿、估值 $20 亿+。
- **用户画像**:短剧工作室(约千家)、影视/广告团队、TVC 团队、AI 漫剧作者;电商场景有渗透原声(「很适合电商中批量制作的需求,即可自己创作,也可以让智能体完成」@搜狐)——**渗透的是「内容量产工业化团队」,不是卖家个体**。
- **流行原因第一条**:把「碰运气」变成「做工程」——「画面跳、角色崩、逻辑乱,想改?改不了,要么重来」→ 节点流全链路可改可复用。**这条痛点与 S5 问题清单(角色一致性/镜间衔接/质量无监督)逐字对应**,只是解法不同:LibTV 给用户画布,我们给用户导演脚本+二审+重roll。

2. **所有以电商卖家为主客群的工具无一例外弃画布**:字节给电商的答案是 Pippit(无时间线,链接→成片)与即梦 Agent 模式(官方示范就是「制作汉服电商素材」);Creatify($9M ARR)走端到端 Agent;CreatOK 无画布;Glif 拿到大钱后第一件事是把工作流藏进 agent。中文跨境选型文的标准是「0 门槛一键成片、零提示词、从输入到导出的最短闭环」。**下一轮交互竞争是 Agent 化,不是画布化。**

### 1.3 复刻难度量化(代码审计底座:studio-shell 8 文件 4,806 行 / BTM 2,066 行 7 执行器 / 12 store 6,142 行 / lib/studio 11 文件 2,896 行)

### 1.4 有没有必要:重合度与方向判定

- **用户重合度(对抗修订:分层结论,不再给单一 <10%)**:
  - **卖家个体段:重合极低,证据充分**(§1.2 铁律 2,即梦/Pippit/CreatOK/Glif 四重反证)。我方 omnibox+批次流+蓝图抽屉与 Pippit/Creatify 同属「结果导向」范式,与目标客群选型标准吻合。
  - **矩阵/工厂团队段:存在实质重合**——LibTV 的 300+ 短剧公司与 MCN 矩阵团队同属「内容量产工业化团队」,且 LibTV 已有电商批量场景渗透原声。若未来付费主力变成多席团队,本判决前提失效(见复评触发器)。
- **与 S5 智能体化裁决:通用画布反向,管线视图同向**。S5 裁决=「出片步骤序列固定,智能放节点内不放流程决策,把复杂度藏起来」;通用画布=把流程决策交还用户。但 S5 自己的路线图里长着节点交互的需求:v1 导演脚本「确认→抽屉阶段」(确认即修改,分镜数/秒数/景别是逐节点操作);v2 镜级质检+重roll(「第 3 镜不过→只重roll 第 3 镜」);候选 C/D 的首镜锚定与尾帧→首帧链式=「改第 3 镜⇒下游失效」的教科书 DAG 语义——**omnibox+420px 抽屉对「改成功镜→选择性重跑下游」没有任何表达方式**(现行代码只有失败镜重试与全量再出 N 条)。
- **蓝图抽屉=「无画布的可控性」**:ComfyUI 走红根因(60-80% 问题、局部修正不重写全局)在我方对应「卖点勾选/逐镜台词编辑/hook 矩阵」——这是把节点流可控性翻译成电商语言的中间态,是对抗一键工具同质化的核心叙事。

### 1.5 判决(三段式)

1. **不做通用无限画布/自由连线**(维持,四路对抗攻不动):工程与市场两条独立推理链指向同一结论——4.5–7.5 人月画布独有增量+四个编排结构性冲突+一人团队冲进 Flora/Weavy/LibTV 的正面战场($5 亿估值玩家+Figma/字节两座山+1.3 亿美元价格战弹药)无胜算。
2. **做「固定拓扑可编辑管线视图」,并入 S5(条件式)**:比草案「只读流程图」升格——蓝图 scenes 线性链+渲染腿扇出的管线图,节点点开编辑(复用 blueprint-drawer 现有行内编辑组件),执行仍走 BTM 零改动;「改镜→镜级选择性重跑」列为 S5 v2 明确交付项。**时点=S5 v1 导演脚本落库且第0步实验阳性之后的第一个填缝任务**(导演脚本数据结构定型后再抽 use-blueprint.ts,一次到位不返工;工期 2–3 周含全屏态与拆解报告/商品蓝图两形态回归——420px 右栏放不下横向链,全屏态是必选不是可选)。
3. **复评触发器(任一命中即重开画布裁决)**:①付费收入中多席团队档占比 >50%;②流失/拒付访谈中「过程不可控/不能只改一段」归因 ≥3 例;③LibTV 或即梦对电商 ICP 上线画布模板市场(造流者→卖家的封装分发闭环);④S5 v2 镜级重roll 上线后,数据表明镜级操作成为主交互面。

**LibTV 值得抄的四样(都不是无限画布)**:①Agent Skill 开源接口(呼应 PRODUCT_STRATEGY 的 MCP 第二曲线,形态参照 libtv-skills:MIT+npx 安装+ACCESS_KEY);②工作流/配方分享经济(配方库已有雏形,可发展「配方市场」);③模型聚合+价格意识(警示:不在通用生成上与其拼价格,守住 $0.02/条幻灯片与方法论层);④**「局部可改可复用」的工程化叙事**(LibTV 走红第一原因,与 S5 问题清单逐字对应)——我方承载物=可编辑管线视图+镜级重roll,这也是管线视图值得做的根本理由。

### 2.3 发布接口:壁垒还是通道?(数据裁决)

**是通道,不是壁垒。**证据:统一发布 API 已是白菜价商品市场——Post-Bridge $9/月、upload-post $16/月、Zernio $6→$1/账号/月(25+ 平台含 WhatsApp)、Postiz 开源自部署免费、Ayrshare(贵价锚)$149-599/月;TikTok audited Direct Post 已确认至少 10 家第三方持有(Buffer/Later/Metricool/Blotato/Repurpose/upload-post/Zernio/Post-Bridge/Postiz/Ayrshare),过审成本=完整产品录屏+2-4 周多轮反馈。**我方已拿到的这张票价值=省下 2-4 周与被拒风险,而非独占。壁垒必须建在发布层之上:爆款拆解→蓝图→批量生成的方法论闭环、$0.02/条的成本结构、中国卖家合规出海的操作层(中文 UI/网络可达/积分制)——这些才是别人用 $9/月 API 拼不出来的部分。**推论:YT/FB/IG 三条腿自建过审的机会成本,应对照「买 Zernio $6/账号/月」重新算账(自建的正当性在数据回流与账号健康管理纵深,不在发布动作本身)。

### 2.5 反方论证(诚实版,五条)

1. **「外贸 SaaS 就不拥挤吗?」——同样红,只是红法不同**:2021 年跨境电商 SaaS 盘子仅 73 亿元(对比通用视频 HeyGen 一家 $200M ARR);2025 年 ERP 渗透率 49.6%、CR5>58%,跑马圈地期已结束;外贸 CRM 第一名小满的结局是被阿里收编当国际站赠品——这是对独立外贸 SaaS 天花板的最直白定价。垂直赛道 B 轮以下融资占比超 50%,「垂直=没人做」不成立。
2. **「通用赛道拥挤所以必须换赛道」是半真半假**:HeyGen/Synthesia $200M ARR 坐实拥挤,但 Creatify(18 个月 $9M ARR)/Arcads(8 人 $10M ARR)证明电商广告视频子赛道 2024-2026 仍容得下小团队——**正确推论是「不能做无差异通用工具」,而非「通用必死、垂直必活」**。
3. **付费锚是最大暗礁**:这个客群为询盘付 3 万/年(阿里),为工具付几千/年(OKKI ¥700/人/年起),且要销售驱动(渠道成本 30-80%);中国 SaaS 原声「付费意愿,SaaS 行业最大的笑话」。积分自助收费与该客群采购习惯真实错位。
4. **单人 SaaS 成功模板三项全反**:已验证先例(Jungle Scout bootstrapped $24M ARR/Keepa €19 月/Arcads)全部=美元定价+全球英语客群+PLG 自助+可量化 ROI;检索多轮**找不到一个「服务中国外贸企业、卖内容生成、活得好」的独立开发者案例**——此空白本身是最响的警报。
5. **时机净值≈中性偏谨慎**:正面=TikTok 美国交易 2026-01 落地(最大不确定性移除)+TikTok Shop 全球 GMV $64.3B(+94%)+B2B 买家年轻化(64% 千禧/GenZ);反面=de minimis 终结抽血直邮卖家现金流+关税 15-30% 常态化+**「批量 AI 内容+矩阵分发」与平台治理方向的结构性对抗(TikTok 已标 13 亿条 AIGC,未标注=strike,补标后触达 48h 内可跌 73%)**。最后一条不是市场问题,是产品叙事前提问题——它对现有电商矩阵定位和外贸新定位同等生效。

### 2.6 候选战略定位(三案,对抗修订版)

**候选 A:全面转型「外贸人 SaaS 工作平台」——否决(三路对抗一致维持)**
- ICP=工厂外贸部;JTBD=「让不会做内容的外贸企业持续产出能来询盘的海外内容」。
- 否决理由(每条单独致命):①付费锚=询盘,内容工具结构上兑现不了(§2.1);②采购=销售驱动,渠道成本 30-80%,一人团队死穴;③多租户零基建,20+ 张表加租户键+RLS 重写=季度级工程;④放弃已上线的电商基本盘。

**候选 B+:不转型,现有产品国际化(「不转型」辩护人的最强版本,被采纳为并行探针)**
- ICP=全球 TikTok Shop/DTC 卖家(付费已被 Creatify $39-99/月验证,GMV 翻倍中);JTBD=「用爆款方法论以 1/10 成本替代 $150-500/条的 UGC 素材预算」。
- 差异化壁垒:爆款拆解→逐镜蓝图(11 家海外竞品无一有此物)+$0.02 幻灯片成本腿+已过审 TikTok 直发。
- 定价:$29/$49/$99 美元订阅(锚 Blotato $29/Creatify $39);ROI 叙事=素材成本替代,当月可兑现——**四项全合单人 SaaS 模板**。
- GTM:产品即 demo(自家产品出英文成片直发 TikTok/YT——同时是 S5 质量回归测试)+Product Hunt+英文 SEO。
- **暗礁(主循环补充,辩护人未提)**:①收美元需要海外主体+Stripe——PRODUCT_STRATEGY §六早已裁决「主体结构 90 天内定案」,至今未办,这是行政硬门槛(周-月级)而非代码问题;②英文获客从零起盘,现有抖音 IP 引流盘完全用不上;③正面撞 Creatify/Pippit 英文市场,「中国团队合规出海」叙事失效。
- 6 个月路线图:90 天=英文 UI i18n+主体/Stripe 行政线+YT/FB/IG 启用(审批落地后)+英文 PLG 内容;180 天=按订阅数据决定加码。
- Kill criteria:90 天英文 waitlist/意向 <100 或首月美元订阅 <10 → 收缩回中文基本盘。

**候选 C′:外贸楔子(草案候选 C 的对抗裁剪版,推荐)**
- **定性:不是转型,不是新客群发明——是 PRODUCT_STRATEGY 既有 ICP②(跨境电商内容团队)向 B2B 工厂侧的半步细分深化。** 产品内核、S5 主线、TikTok 电商基本盘全部不动。
- ICP(优先序):①已在做 TikTok 的工厂外贸部(有运营人手、缺内容产能——不做冷启动教育);②独立站 DTC 卖家(付费最成熟);③外贸业务员(低 ARPU 引流层,幻灯片/图文帖免费额度)。
- JTBD:「把 #factory 爆款的结构变成我的工厂/产品的多语种内容,合规直发,不用懂脚本不用学剪辑」。
- 差异化壁垒:四要素组合(拆解×生成×官方直发×批量)+assembly 腿与工厂实拍素材的场景 fit+中文操作界面出海外内容(结构性空档,§2.2)。护城河的诚实评估:发布层是通道(§2.3),真壁垒只有方法论层(门B+配方)与成本结构——**中等厚度,须靠语料与配方生态持续加厚**。
- 定价(对抗修订):个人档 **≤¥99/月**(贴 CreatOK ¥58 锚,不再顶 ¥199);**砍掉 ¥999 自助订阅档**,工厂客群 90 天内只做「案例包一次性付费 ¥3,000-5,000」试销(验证成交方式而非订阅价);叙事锚挂「**素材成本替代+多语种产能**」(当月可算清:代运营数万/月 vs 工具 ¥99/月),**询盘只作 case study 素材、不作付费承诺**(成交责任显式留给客户)。
- GTM(对抗修订):种子从 10 家砍到 **3 家已在做 TikTok 的工厂**(客户成功压到每周 1 天内);少伯抖音号**不转向**,以职场提效定位加挂外贸案例内容 A/B;米课圈/福步只发案例贴引流(写下可证伪转化假设:案例贴→注册 ≥2%),不做地推承诺。
- 6 个月路线图:见 §2.8 合流时间线。
- Kill criteria(对抗修订,全部改为可测量+补供给侧闸):
  1. 【地基闸,第 1 周】门B 英文/#factory 语料基准 <80 分或解析率 <90% → 玩法 1 撤下,外贸包降级为「配方+en 出片」纯功能;
  2. 【种子闸,90 天】3 家种子中 <2 家周活跃出片,或 0 家愿付案例包/≤¥99 订阅 → 停止外贸投入,资源转候选 B+;
  3. 【归因闸,90 天】wa.me 短链合计点击/会话发起 <50 次 → 降级询盘叙事为纯素材叙事;
  4. 【供给侧闸,持续】任一周 S5 主线零进展≥2 周 → 外贸包冻结(质量线是前置,不许被挤压);
  5. 【竞争闸,双触发】阿里(生意助手×OKKI Shops 站外直发接线迹象)或 **字节 Pippit(上线爆款拆解/中文界面/LinkedIn 支持)** 任一命中 → 重估差异化叙事。

### 2.7 两个 90 天差异化玩法(对抗修订版,含依赖闸)

**玩法 1:爆款结构移植·外贸版**——「选/传一条 #factory 或同类目爆款 → 结构报告(hook 类型/逐镜台词/节奏/CTA)→ 换成我的产品 → 英文成片×N 变体 → TikTok 直发」。
- 竞品空白证实:CreatOK 的「爆款复刻」仅 TikTok 单平台、无 B2B 语域;国内外贸 SaaS 9 家、海外 11 家全无「上传爆款→逐镜结构拆解→反向生成」。
- **90 天可交付形态(诚实版)**:门B 拆解+结构报告(已上线)+**模板级**换商品(现有 buildScenes+配方填槽)+en 出片(已通)——今天就能拼出可演示的 v0。
- **依赖闸(对抗实锤)**:全形态(LLM 逐镜重写保结构)=S5 v1 E 项,押在第0步 A/B 实验阳性上;98.8 分基准是中文带货语料,**英文 #factory 语域零验证——第 1 周先跑 10-20 条小基准证伪地基(半天成本)**。基准评分卡加「实拍感/可信度」维度。

**玩法 2:一鱼 N 吃跨语域内容包**——「1 份素材(产线实拍/商品图)→ TikTok 视频+TikTok 图文+LinkedIn B2B 专业帖+SEO 博文骨架,语域逐渠道改写(带货体 vs 专业体),能直发的直发、不能的导出」。
- 竞品空白证实:Repurpose($35/月)只搬运不改语域;Ocoya/Predis 无中文无方法论;外贸 SaaS 无视频。
- **90 天可交付形态=「一鱼三吃」**:TikTok 视频+图文(直发已生产实跑)+LinkedIn 帖**导出包**(个人号 w_member_social 直发若核验自助可得则升级为直发)+SEO 博文 markdown 导出(零审批)。
- **依赖闸(对抗实锤,fatal 级修正)**:五吃全直发形态的四个依赖每个都可能单独吃掉 30-90 天——Google verification/Meta App Review 状态未知(仓库零记录)、LinkedIn Community Management API 公司主页发布需合作方审批、Adapter 尚不存在、teammate +11,428 行未评审。**第 0 周启动外部时钟(审批核验+提交),内容侧先交三吃,YT/FB/IG/LinkedIn 公司页直发等审批落地再逐个开。**

### 2.8 推荐定位与合流时间线

**推荐:候选 C′(外贸楔子)为主 + 候选 B+(国际化)零代码探针并行,120 天带数据选边;S5 质量主线是 90 天内唯一确定的重工程投入,Adapter 一期是唯一确定的次工程投入。**

推荐理由(对三案的比较裁决):A 三刀毙命不复议;B+ 模板四项全合但卡在主体/收款行政线与获客从零,不适合作 90 天主攻,适合作低成本探针+把行政线(主体定案)现在启动——这本来就是 PRODUCT_STRATEGY 的既有欠账;C′ 的机会证据(四要素空白)与风险证据(付费锚/坟场读法)五五开,但**验证成本被压到近零(配方=数据、en=已通、短链=零 API、种子=3 家)**,值得用 90 天买这个信息;两轨共享同一个前置(S5 质量线)与同一批确定性资产(门B/配方/发布基建),不选边的代价极低。

**合流时间线(一人团队带宽账)**:
- **第 0 周(并行,近零开发)**:①登 Google/Meta/LinkedIn/WhatsApp 开发者后台核验审批状态、提交缺失申请(启动外部时钟,需用户账号配合);②门B 英文/#factory 小基准 10-20 条(半天);③主体/Stripe 行政调研启动(B+ 探针+PRODUCT_STRATEGY 欠账)。
- **第 1-6 周(主线=S5)**:第0步双实验(A/B 盲评导演脚本+二审 vs 模板;角色一致性实测)→ 实验阳性则 v1(总导演节点+二审环+E 项)。**外贸侧仅数据工作**:外贸配方种子包+门B 外贸语料库;wa.me 短链+UTM(1-2 天);英文 landing page(B+ 探针)。
- **第 4-8 周(并行次线=Adapter)**:一期包壳(前置:核 dashboard SQL 001→005 已落库什么)——理由独立于外贸(teammate 收编+YT/FB/IG 启用都压在它上面)。
- **第 6-12 周**:3 家工厂种子上线陪跑(每周 ≤1 天客户成功);玩法 1 v0(模板级)+玩法 2 三吃形态交付;审批落地的平台逐个开(美国 worker 届时激活);S5 v1 落库后做管线视图(课题一最小形态,填缝)。
- **第 120 天:选边裁决**——外贸轨(种子活跃/案例包成交/短链数据)vs 国际化轨(waitlist/主体进度),按 kill criteria 五闸判定加码方向。
- **明确不做(90 天内)**:teammate 分支合并、WhatsApp inbox、es/ar、¥999 订阅档、10 家种子、少伯号转向、通用画布。

**与 S5 的关系(总裁决)**:S5 主线**不改写、不让位**——它同时是玩法 1 的引擎(E 项)、B2B 可信度的前置、B+ 路线的产品底气,四路对抗无一路能撼动;Adapter 并行线**提级为建议先行**(独立理由:LinkedIn 第 5 次 5 表克隆实锤);自动化流水线维持后置;本评估**兼容而非改写 S5 排期**,新增的只有第 0 周外部时钟与外贸数据工作。
