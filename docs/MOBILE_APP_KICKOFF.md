你是 Star Gaze 项目的战略+产品规划智能体。本篇章任务 = **深度市场调研 + 形成《手机 App 总体方案》(决策级文档 + 白话版 PDF)**。只做研究与方案设计,不写产品代码。用多智能体工作流(ultracode)做调研与对抗反驳,方案落盘前必须过至少「工程可行性 / 商业单位经济 / 平台政策合规」三视角的对抗轮。

## 二、产品构想(用户原话要点,2026-07-11 拍板)

- **形态**:手机 App(iOS 优先),像 TikTok/YouTube 那样的「真 App」体验;**上架美国区 App Store**(不上中国区)。
- **三大功能支柱**:
  1. **集中发布**:拍一条视频(App 内相机或相册)→ 勾选平台 → 一键发布到 TikTok/YouTube/Instagram/Facebook(能接的都接,未来可扩中国区平台如抖音/视频号)+ AI 自动生成各平台标题/文案;
  2. **统一私信收件箱**:聚合各平台私信为一个信息列表,用户不用逐个 App 查看;可在 App 内直接回复 WhatsApp、Telegram 等的消息;
  3. **轻量媒体浏览**:App 内可浏览一些媒体信息/内容(增强「真 App」感,具体形态待方案定义)。
- **目标用户**:①中国外贸从业者为主(卖车/百货/工厂等)——**默认他们已具备海外 Apple ID + 手机全局 VPN,不需要解决翻墙/下载问题**(这是用户明确的给定假设);②美国及全球用户同样欢迎。
- **发布接口策略**:**先借第三方统一发布接口起步**(候选:Post Bridge / upload-post / Zernio / Ayrshare),同时逐步自建官方接口(我方 TikTok 已过审)。
- **最终产出预期**:总体方案 PDF → 用户按方案开发 App → 持续迭代。

## 三、已验证事实(前序三轮调研结论,直接采信;如需复核请显式标注「复核」并给新证据)

以下结论来自 2026-07-10/11 的四轮多智能体调研(中国区评估 6 路、紫鸟评估 3 路、美区评估 3 路、统一发布接口市场 2 轮),原始依据存档于 docs/STRATEGY_PIVOT_EVALUATION.md 所属会话;关键事实:

**上架与合规**
- 中国区上架不可行:ICP 备案强校验+审核,「发境外被墙平台」写不进可获批业务范围;蚁小二的中国区 App 只放境内平台、海外功能全在 PC 端(行业标准切法)。
- 美区上架可行,三绿一黄:中国主体只上美区=标准操作零额外资质;多平台发布工具品类无审核障碍(Buffer/Later 先例);审核四件套=自建账号体系(豁免 Sign in with Apple)+App 内可注销+隐私营养标签+**保留免费层**(纯登录曾有 HEY 被拒先例)+给审核员英文备注和 demo 账号。
- 收款:「App 纯登录使用、付费全在网页(支付宝/微信/Stripe)」合规且是 Buffer/Slack 惯例;2026-07 美区处于 Epic 判决后**外链收款 0% 佣金窗口期**(第九巡回已裁定苹果可收「合理佣金」、费率待核、SCOTUS 已授 cert)——财务模型按未来交个位数至低两位数佣金预留。中国个人开发者美元结汇年 5 万美元额度;规模化需香港/海外主体(与既有战略 B+ 路线的主体欠账是同一件事)。
- 安卓:官网直发 APK 不触发备案强制(海外服务器+不进境内商店),对全局 VPN 用户分发无碍;真瓶颈=境内微信/支付宝商户收款要 ICP,绕法 Stripe 跨境 Alipay+海外主体。

**授权与网络(生死关,已钉死)**
- TikTok/YT/Meta OAuth 协议强制用户在自己设备上访问平台官方页完成,服务端不可代办;四平台在中国大陆全被墙。
- 手机**全局 VPN** 覆盖 OAuth 全流程(与桌面紫鸟「按环境代理」不同)→ 已装 TikTok/WhatsApp 的目标人群授权可行;裸网小白不可行——**本产品的用户定义必须锁定「已装备人群」**,这已是给定假设。
- 第三方发布接口(Ayrshare 官方确认)同样不能代办授权,只省接口对接工程量。

**竞品与市场(美区,2026-07)**
- 「打开即相机→拍完勾选→官方 API 直发四平台」完整闭环在美区**无成品**;两家各差一步:Crosspost($9.99-16.99/月,9 平台+App 内相机,但相机直发只点名 IG/Snapchat/FB、无 AI 标题、仅 38 评分)、Socialync($10/月,6 平台+每平台 AI 标题+视频转录,无相机,13 评分)。窗口以月计。
- 大厂移动端(Buffer 4.7★/3.4 万评、Later、Metricool)全是「相册上传+排期」,无一 camera-first;Metricool 不支持录制(纠正过的结论)。
- 2025-26 美区扎堆出现「双画幅同录」相机 App(DualShot 等,只拍不发)——「为多平台拍一次」需求真实。
- 独立对标品评分数极低(38/13)→ **App Store 自然流量撑不起冷启动**,获客必须自带渠道。
- 中国侧:蚁小二 PC 免费档已做 5 大海外平台一键分发(分发被锚定为免费/48 元功能);义乌官方 Chinagoods AI(36 语种视频+一键转发)政府补贴截胡低端。

**平台 API 硬限制(直接决定产品体验上限)**
- **YouTube:videos.insert 每次 1600 配额单位,默认项目配额 1 万/天 = 全 App 所有用户合计约 6 条/天;须最早启动配额扩容申请+审计**(四平台中最致命隐形门槛)。
- TikTok:我方 **Direct Post 已过审生产在用(核心资产,竞品没有)**;每创作者约 15 条/天(全第三方共享);**API 拿不到热门音乐**(商家型内容不受影响,反而圈定客群);新客户端未过审=5 用户/24h+强制私密。
- IG Reels:仅 Business/Creator 账号可 API 发布(需关联 FB Page,onboarding 有流失),每账号约 25 条/24h(有 100 条口径分歧)。
- FB Reels:仅 Page 可发,9:16、3-90 秒、≥720p。
- **WhatsApp Status 无公开 API,但官方文档明文支持第三方 App 经 iOS URL Scheme/Android Intent 把视频直送 Status 编辑器(用户确认后发布)——Web 物理做不到,是 App 独有王牌**,且压在外贸人最高频私域动作(发车源/产品到 Status)上。

**第三方统一发布接口(用户已拍板起步用它)**
- 价格与账号规矩:Post Bridge $9/月起($29=15 账号/$49 不限);upload-post $16/月=5 账号不限量,可扩 225+;Zernio 前 2 账号免费、$6→$1/账号/月阶梯、25+平台;Ayrshare $149-599/月(唯一明确白标/多租户,按终端用户 profile 计费:30 用户 $599→1000 用户约 $3.35/用户);Postiz 开源自部署免费。付费档条数普遍不限(平台官方限额才是天花板)。
- 风险(方案必须体现):单点依赖(TikTok 曾集体吊销 Streamlabs 等第三方权限)、白标法律条款均需 contact sales 确认、低价家多为单人项目存续性差;单位经济在 <500 用户时每用户 $4.7-20/月,定价必须覆盖。
- **混合策略是既定方向:TikTok 走我方自有过审接口(COGS≈0),其余平台先借第三方,同时自建审批推进**。

**目标人群行为与付费(人群①=中国外贸卖家)**
- 「会用」大概率成立:头部平行出口车商多平台日更实锤;剪映导出→逐 App 上传是普遍工作流;海外 ID+全局 VPN 是既成事实(装 TikTok 的必要条件)。
- 「愿付费」证据不足:散户真痛在微信群+WhatsApp 私聊分发;公域一键多发被免费工具锚定;付费盘估算仅千级用户/月流水数万元。已验证付费肌肉:VPN 15-60 元/紫鸟 40-68 元/云手机 48-158 元/月,合理价位带 $5-15/月。
- **营收假设押人群②(美国本土商家,支付零摩擦、市场已被 Buffer 教育);人群①当种子/口碑渠道**。美区 ID 充值通路:支付宝国际区买礼品卡(ChatGPT Plus 同路径先例),可行但有漏斗。

**我方资产(代码级,可复用)**
- Star Gaze(Next.js 14+Supabase+阿里云,生产站 www.toryxai.com):TikTok 发布全套生产在用(视频+图文直发、队列、多账号矩阵表、cron 驱动=天然适配移动端);YT/FB/IG 发布代码完整在库(被 PUBLISH_SKIP_OVERSEAS=1 关闭,OAuth 审批状态待核);AI 内容引擎(五腿+爆款拆解 98.8 分+配方+多语文案 deepseek/qwen+TTS);OSS 直传签名(手机拍完直传天然适配)。
- 移动化审计结论:走「App 薄壳(拍摄+直传+调 API+推送)+重逻辑留服务器」,**后端复用 80%+**;BTM(浏览器执行引擎)不能搬手机,视频编排需下沉服务端(照抄已有 publish/image cron 范式);会话 cookie→bearer token 小改;技术选型 Capacitor(UI 复用最高)vs RN(原生体验),Flutter 复用最低。

## 四、必须深度调研的开放问题(新窗口主战场,按优先级)

**P0 · 统一私信收件箱的平台可行性矩阵(全新领域,前序未调研,是本方案成败第二关)**
逐平台钉死「能不能合规接入私信收发」,输出可行性矩阵(可行/受限/物理不可能/灰色+风险定级):
1. TikTok:有没有任何第三方可用的 DM API?(初步印象:普通号无公开 DM API,Business Messaging 是否存在/开放给谁?)
2. Instagram:Messenger Platform 的 IG Messaging API——需要什么审核/账号类型/权限,消息窗口限制(24h?),先例产品;
3. Facebook:Messenger Platform 对 Page 消息的支持与审核;
4. WhatsApp:个人号无 API(钉死);Business API 按商家逐个验证+按条计费,能否以「用户自带 WABA」形态接入收件箱?或只做「点开跳转 WhatsApp App」的浅集成?
5. Telegram:Bot API(只能收发给 bot 的消息,读不了用户私信)vs 用户号 MTProto 库(Telethon 类)——封号风险与 ToS 定性,消费级产品敢不敢用;
6. LINE(外贸东南亚/日本场景)、Messenger、X DM 顺带;
7. **统一消息聚合 API 服务商实调**:Unipile、Beeper(Automattic,Matrix bridges,消费级统一收件箱先例+它和苹果的 iMessage 冲突史)、respond.io、ManyChat 等——覆盖哪些平台私信、定价、白标、合规姿势;「借第三方私信聚合接口」是否比逐平台自建更现实?
8. 诚实判定:三大支柱里「统一收件箱」的可交付比例到底多少?哪些平台注定只能做「通知聚合+跳转原 App」的降级形态?

**P1 · 「轻量媒体浏览」的合规边界**
- 聚合浏览第三方平台内容流的 ToS 风险(第三方 TikTok/IG 客户端被封史);官方 oEmbed/Display API 能合规展示什么;方案里该把这个功能定义成什么形态才安全(如:仅展示用户自己账号的已发内容+数据,而非公域 feed)。

**P2 · 发布底座终选与单位经济**
- 结合三大支柱重新选型:哪家第三方接口同时覆盖发布+(部分)私信?白标合同条款(须 contact sales 的项列成待办);混合架构(TikTok 自有+其余借)下,按 $9.99/月定价、免费层限额多少条,画出 100/500/2000 用户三档的毛利表。

**P3 · 技术架构与 MVP 切分**
- Capacitor vs RN 终选(结合我方代码复用事实);推送(APNs)、后台上传、深链回跳 OAuth 的具体方案;
- MVP(V1)建议边界:相机/相册+一键发 TikTok(自有)+IG/FB/YT(借)+AI 标题+WhatsApp Status 分享;V2:统一收件箱(按 P0 矩阵裁);V3:媒体浏览/中国平台。由调研修正。
- YouTube 配额扩容申请、Google/Meta OAuth 应用审批:作为「第 0 周外部时钟」写进路线图(我方仓库内审批状态零记录,须登开发者后台核验)。

**P4 · 竞品动态复核与定价/GTM**
- Crosspost/Socialync 是否已补齐缺口(窗口关闭信号);Beeper 现状;
- 定价:免费层+$9.99/月锚(对标 Crosspost),人群①种子策略(免费/低价换案例)、人群②获客(ASO/Product Hunt/英文内容);
- Kill criteria:延用已定框架(120 天人群①付费转化 <3% 放弃其付费预期;Crosspost 补齐 TikTok+AI 标题=窗口关闭重估),并补私信支柱专属止损线。
