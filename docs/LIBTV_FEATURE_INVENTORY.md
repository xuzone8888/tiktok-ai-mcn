## ★ 创作逻辑链(核心洞察)
LibTV 管线 = **结构化分镜 → 资产装配(保一致性)→ 逐镜生图 → 图生视频 → 配音 → 合成成片**。四快捷位=四起点,共用同一管线:
1. 故事脚本生成(漫剧起点):剧本节点(原始故事)→ 脚本生成器(拆分镜)
2. 角色三视图(角色资产):角色图 → 三视图(多角度呈现板)
3. 首帧图生视频(通用):图片节点(首帧)→ 视频节点(图生视频)
4. 音频生视频(配音):音频 → 视频

## 节点 A:剧本节点(文本类,漫剧起点)[实测]
结构化故事简报:标题《我在盛唐写天下》/ 类型(古风/穿越/爽文漫剧)/ 时长建议(60-90秒)/ 基调(热血×盛唐史诗感×爽点节奏)/ 分场(【序幕】【现代·深夜办公室】…逐场景描述)。可编辑文本,作脚本上游。

## 节点 B:脚本节点(★★★漫剧心脏,三步向导,全屏)[实测]
三步进度:①确认镜头 ②准备资产 ③合成提示词;右上"1/3 完成后可批量生视频"。模型 GVLM 3.1,⚡6。

### ①确认镜头 = 分镜表(LLM 一次生成 17 镜,9 维度)
列:**镜号 | 时长(5s/6s) | 画面描述(★含 @资产引用,蓝色高亮) | 景别 | 光影氛围 | 对白·旁白 | 音效 | 运镜 | 最终提示词(待编译) | 操作(···)**
- **@资产**:画面描述自动 @ 角色/场景/道具(@现代沈昭昭 @唐朝沈昭昭 @盛唐金銮殿 @皇帝 @处刑大刀 @长安城),同一角色可多版本(现代/唐朝)。
- 景别枚举:大远景/远景/全景/全身景/中景/半身像/中近景/近景/特写/大特写。
- 运镜:自由文本 + 预设 chips(推镜/拉镜/摇镜/跟镜/俯拍/仰拍)。
- 每镜独立:光影氛围/音效/运镜均 LLM 逐镜生成(非模板);有台词的镜写对白。
- 底部:「添加镜头」「下一步:准备资产」。

### ②准备资产 = ★★★角色一致性核心机制
- **全局风格**:盛唐古风·国风二次元(整片统一风格标签)。
- **三类资产区**:角色/场景/道具,每类可「+新增」。
- **系统自动从分镜识别资产并归类**(实测:4 角色 + 2 场景 + 1 道具 = 7 个待设定)。
- **每个资产自带 AI 生成的详细设定描述**(编辑角色抽屉实测):角色卡 = 角色形象(生成/上传占位)+ 角色名称 + 角色描述(极详细:年龄/身高/体型/发型/脸型/瞳色/肤色/标志特征[如泪痣]/服装/神态 + 设定图生成规则)。
- **★角色一致性黄金 prompt(自动写入描述,建议直接复用)**:
  > 「高质量专业角色设定图,横向构图,纯白色纯净背景,中性摄影棚灯光,平光布光;布局结构:**正面半身特写 + 全身正面居中 + 左侧面视图 + 背面视图**,无任何道具或背景物体;确保所有视图中的面部特征、发型、体型和服装保持一致;不得出现道具/武器/其他角色/文字/水印/背景;[视觉风格:X]」
  = 4 视图设定图 + 强一致性约束。场景卡=场景描述(室内/外/尺度/背景);道具卡=六视图详细描述。
- 每资产三来源:**AI 生成 / 从当前画布选择 / 本地上传**;底部「**一键生成所有资产**」批量出全部设定图。
- 资产不齐门控③(0/7 未生成时步③灰)。

### ③合成提示词
资产齐后,每镜分镜信息 + 引用资产 → 编译逐镜「最终提示词」→ 顶栏「重新生成 / 批量生成分镜 / 批量生视频 / 导出」。

## 节点 C:图片节点 [实测]
- chips:+参考 / 标记 / 风格。
- 提示词:"可直接文字生图;或上传图片输入文字指令对图片进行编辑,如:将背景改为雪夜"(文生图+指令式编辑二合一)。
- 参数:**画质**(低/标准/高)· **清晰度**(1K/2K/4K)· **比例 13 种**(1:1/1:2/2:1/9:16/16:9/3:4/4:3/3:2/2:3/5:4/4:5/21:9/9:21)· **生成数量**(1/2/4 张)。
- 模型 14 个(Lib Image/Navo Pro/Navo 2/Seedream 5.0 Pro/悠船 V8.1/V7/Niji7/Seedream 5.0 Lite/4.5/Z-image Turbo/Lib Navo/Qwen Image/Qwen Edit/Seedream 4.0)。
- 内嵌工具条:人像质感调节/全景/多角度/打光/九宫格/高清/宫格切分/(扩图/局部重绘/擦除/抠图/裁剪/标注 前次记)。
- 空态:图生图 / 图片高清。

## 节点 D:视频节点 [实测]
- chips:+参考 / 标记 / 特效 / 角色库 / 运镜。
- 提示词:"描述你想要生成的画面内容,@引用素材"。
- **五模式**(下拉,按上游图灰置):文生视频 / 全能参考 / 图生视频 / 首尾帧 / 图片参考。
- 参数:**比例**(Auto/16:9/4:3/1:1/3:4/9:16/21:9,7种)· **清晰度**(480P/720P/1080P/4K)· **视频时长**(滑杆)· **★生成音频开关**(Seedance 2.0 原生音画同步)· **生成数量**(1/2个)。
- **★运镜库**(运镜 chip):三 tab = 运镜广场(预设镜头:固定镜头/跟随拍摄/盘旋抬升/盘旋下降/镜头上摇/下摇/左摇/右摇…每个示范视频卡)/ 我的收藏 / 我的运镜(自定义)+ 搜索。
- 模型 15+(Seedance 2.0/Fast/Mini/HappyHorse/Kling O3/3.0/O1/Wan/Hailuo/Seedance1.5Pro)。
- 编辑:画布内裁剪/超分/插帧 30-60-90fps/拉片分析。空态:首帧生成视频 / 首尾帧生成视频。

## 节点 E:音频节点(TTS)[实测]
- chips:停顿 `<#>` / 语气词 `()`(文本内插停顿、语气词标记)。
- 文本框上限 **5 万字**(0/50000)。模型 max-speech-2.8-hd;音色库(少女音色等);翻译图标。
- 空态:音频生视频。音乐生成 Mureka V8(可能在模型切换)。

## ★★★ 电商 vs 漫剧 双轨统一(核心结论 — 回答用户"相似地方怎么分细")
管线本质 = **「结构化分镜 → 资产装配(保一致性)→ 逐镜生图 → 图生视频 → 配音 → 合成」**,起点可换:

| 环节 | 漫剧版 | 电商版 | 共用? |
|---|---|---|---|
| 起点 | 剧本节点(故事/类型/基调/分场) | 商品节点(商品图/链接→卖点卡) | 起点不同,**下游全共用** |
| 分镜生成 | 剧情 → 17 镜分镜表 | 卖点 → N 镜带货分镜 | ✅ 同一分镜表(9 维度) |
| 资产装配 | 角色(人物)/场景/道具 | 角色(模特)/场景(拍摄场景)/道具(商品) | ✅ 同一三类 + 一致性 prompt |
| 逐镜生图 | 引用角色/场景资产生分镜图 | 引用商品/模特资产生场景图 | ✅ 完全共用 |
| 图生视频 | Seedance 图生视频 + 运镜 | 同 | ✅ 完全共用 |
| 配音 | 角色台词 TTS | 口播卖点 TTS | ✅ 完全共用 |
| 合成 | 拼接成片 | 拼接 + 直发 TikTok | ✅ 共用 + 电商多直发出口 |

**结论**:StarGaze 只需做一套「分镜→资产→图→视频→音频→合成」中台,前端提供两种起点节点(**剧本节点** / **商品节点**)。资产装配三类(角色/场景/道具)+ 一致性黄金 prompt 是双轨共同的一致性底座——这就是用户说的"电商和漫剧的相似地方"。
