# Star Gaze Studio — S3+S4 UI 人工验收走查清单

> 一份连贯的手动验收脚本,按界面/操作顺序编排。操作对象:**已登录的** http://localhost:3100。
> 每步逐字保留真实 UI 文案。勾选框 `- [ ]` 表示"这一步通过"。

## 验收前提(开跑前先确认)

- [ ] 本地 dev 服务在 **http://localhost:3100** 运行中,且当前浏览器**已登录**(能看到侧边栏与 /studio 工作台)。
- [ ] 门B 拆解 flag 已开:环境变量 **`NEXT_PUBLIC_ENABLE_DECONSTRUCT=1`**(否则第四节「爆款拆解」按钮整个不出现)。
- [ ] (若想跑图片模式的 @角色一致性引用)本机可选设 `NEXT_PUBLIC_ENABLE_DECONSTRUCT=1` 同上。
- [ ] 准备**一个已授权的 TikTok 账号**,用于第三节实测「直发一条图文」(标 ⚠️ 的步骤需要它;没有也能验大部分交互)。

**图例:** ⚠️ **需授权账号** = 该步须真实 TikTok 账号才能验;**(手感)** = 只验交互,后端逻辑已脚本验过;其余步骤走后端、请按预期核对数据结果。

## 一、Omnibox 各创作模式出片

### 1.1 模式切换器(底部悬浮 Omnibox,参数 chips 行左侧)

- [ ] **1.1** **【操作】** 确认参数 chips 行左侧的模式切换器,依次点击「图片」「视频」「幻灯片」「商品成片」四个按钮(若 flag 已开还多一个「爆款拆解」)。
  **【预期】** 切换器是一个圆角深色分段控件,按钮逐字为 **图片 / 视频 / 幻灯片 / 商品成片**(默认停在「图片」);flag 开时最右多一个 **爆款拆解**。当前选中按钮底色变亮(`bg-white/15` 白字),其余灰字;点谁谁高亮,下方参数 chips 行随之整组切换。**(手感)**
  *(切换器是模式唯一真值,自动意图判定永不代切模式。)*

### 1.2 图片模式

- [ ] **1.2** **【操作】** 切到「图片」模式,展开第一个下拉(比例)核对选项;再展开第二个下拉(分辨率)核对;看文本框占位符与右侧估价。
  **【预期】** 比例下拉逐字:**自动比例 / 1:1 / 9:16 / 16:9 / 3:4 / 4:3**(默认「自动比例」);分辨率下拉:**1K / 2K / 4K**(默认 1K)。文本框占位符「**描述你要的图片,可拖入参考图…**」。最右出现「**×1**」数量 stepper 与「**⚡ ≈ <积分> / 余额 <数字>**」估价。**(手感)**

### 1.3 视频模式

- [ ] **1.3** **【操作】** 切到「视频」模式,依次展开:模型 / 比例 / 时长 / 画质(画质仅在该模型有多档时出现),核对模型下拉全部标签。
  **【预期】** 模型下拉逐字含:**Sora 2 / Sora 2 Pro / Seedance / HappyHorse / VEO / Grok / Omni**(默认 Sora 2);比例:**9:16 / 16:9**(默认 9:16);时长为「**<秒数>s**」若干档(默认 12s);画质下拉(有多档时)「**高清 / 标准**」(默认标准)。文本框占位符「**描述你要的视频,或拖入素材图(拖图+文字=图生视频)…**」。**(手感)**
  *(时长/画质档位按模型算;quality 只有 >1 档才显示该下拉。)*

### 1.4 幻灯片模式

- [ ] **1.4** **【操作】** 切到「幻灯片」模式,核对下拉:比例 / 每图秒数 / 转场,以及三个开关 chip「运镜」「配音」「BGM」;逐个点开关 chip 观察高亮切换。
  **【预期】** 比例 **9:16 / 16:9**(默认 9:16);每图秒数逐字「**2s/图**」「**2.5s/图**」「**3s/图**」「**4s/图**」(默认 2s/图);转场逐字:**淡入淡出 / 左滑 / 擦除 / 圆形展开 / 硬切**(默认淡入淡出)。三个开关 chip 文案「**运镜**」「**配音**」「**BGM**」,默认三者均高亮(蓝底);点一下变灰(未激活),再点恢复蓝。文本框占位符「**拖入 2-15 张图;这里写文案主题(可选,AI 生成口播文案与配音)…**」。**(手感)**

### 1.5 商品成片模式 — 进入 + 渲染腿切换器

- [ ] **1.5** **【操作】** 切到「商品成片」模式,观察参数 chips 行是否新增一个琥珀色分段控件(渲染腿),核对四个腿按钮标签并依次点击切换。
  **【预期】** 出现第二个分段控件(渲染腿),四个按钮逐字:**幻灯片 / 拼装口播 / AI 生成 / 图文帖**(默认停在「幻灯片」)。选中腿高亮琥珀色(`bg-amber-500/20 text-amber-300`),其余灰字;切腿会整组更换下方参数 chips。文本框占位符「**拖入 2-9 张商品图,或粘贴 Amazon/Shopify/TikTok Shop 商品链接;发送=按勾选卖点批量出成片**」。**(手感)**

- [ ] **1.6** **【操作】** 商品成片下保持渲染腿=「幻灯片」(默认腿),核对参数 chips。
  **【预期】** 与幻灯片模式一致:比例(9:16/16:9)、每图秒数(2s/图…4s/图)、转场(淡入淡出/左滑/擦除/圆形展开/硬切)、以及「运镜」「配音」「BGM」三开关。计价按图数分级(≤5图=1分,≤10图=2分,否则3分),估价条随勾选/图数变化。

- [ ] **1.7** **【操作】** 商品成片下点渲染腿「AI 生成」,核对参数 chips。
  **【预期】** 参数 chips 切换为视频那一套:模型下拉(Sora 2…Omni)、比例(9:16/16:9)、时长(<秒数>s)、画质(高清/标准,多档时)。估价按「逐镜 video 计价 × 镜数 × 条数」,数值明显高于幻灯片腿。

- [ ] **1.8** **【操作】** 商品成片下点渲染腿「拼装口播」,核对参数 chips 与提示文案。
  **【预期】** 参数 chips:比例下拉(9:16/16:9)、每图秒数下拉但文案为「**2s/镜起**」「**2.5s/镜起**」「**3s/镜起**」「**4s/镜起**」、开关 chip「**运镜**」,末尾灰字提示「**逐镜口播+字幕(镜长随台词自动延长)**」。比幻灯片腿少了转场、配音、BGM。计价=1 积分/镜。

- [ ] **1.9** **【操作】** 商品成片下点渲染腿「图文帖」,核对参数区提示文案。
  **【预期】** 参数区无下拉,仅一行灰字提示「**图=素材图序(每条独立洗牌),文案 AI 生成;免费,可直发 TikTok 图文**」。估价条显示「**≈ 0**」(免费)。

- [ ] **1.10** **【操作】** 商品成片模式点渲染腿右侧的配方下拉(默认显示「默认结构」),展开核对选项。
  **【预期】** 下拉首项逐字「**默认结构**」;下面是内置配方项(前缀 **📐**)与用户配方项(前缀 **📕**)。选中某内置配方后,渲染腿/比例/每镜秒数会按该配方预设自动切换。**(手感)**
  *(用户配方列表需登录态拉 `/api/studio/recipes`,但下拉本身与「默认结构」「📐 内置」始终可见。)*

### 1.6 商品成片 — 链接 chip 与商品卡 chip

- [ ] **1.11** **【操作】** 商品成片模式,把一条商品链接(Amazon/Shopify/TikTok Shop)粘贴进文本框。
  **【预期】** 链接**不进输入框**,顶部出现蓝色链接 chip(Link2 图标):解析中显示 URL + 转圈 + 「**抓取商品页并提炼卖点…**」,右侧有「**取消 (Esc)**」按钮;完成后变「**<域名> 已解析**」;失败显示红色错误文案 + 「**重试**」按钮。URL 之外的文字保留进文本框作文案主题。(走后端解析;Esc 可取消进行中解析。)

- [ ] **1.12** **【操作】** 商品成片模式,通过左侧 ImagePlus 按钮或拖拽上传 **2-9 张**商品图,等自动分析完成后点出现的琥珀色商品卡 chip 展开。
  **【预期】** 上传完成自动分析:先显示蓝色「**正在分析商品图,提炼卖点…**」转圈;成功后出现琥珀色商品卡 chip(Package 图标 + 商品标题 + 右侧「**卖点 <已选>/<总数>**」+ 上下箭头)。点 chip 展开面板,列出各卖点复选框(勾选态 accent-amber),底部可能有「目标人群:xxx、yyy」。分析失败显示红色错误 + 「**重试**」。(需 ≥2 张图才触发分析。)

### 1.7 @角色浮层(仅图片/视频模式)

- [ ] **1.13** **【操作】** 切到「图片」或「视频」模式,点输入区的 AtSign(@)按钮,或在文本框输入「@」字符。
  **【预期】** Omnibox 上方弹出「**@角色 · 一致性引用**」浮层(CharacterPicker),右上角有关闭 X。选中一个角色后浮层关闭,参数 chips 行出现紫色 @chip:「**@<角色名>**」(紫底,带头像或 AtSign 图标 + 右侧 X 移除)。输入 @ 只唤起浮层、不吞字符。**(手感)**

- [ ] **1.14** **【操作】** 打开 @角色浮层后按 Esc;再切到「幻灯片」或「商品成片」模式,把鼠标悬停到 @ 按钮上。
  **【预期】** 按 Esc 浮层关闭。在幻灯片/商品成片模式,@ 按钮变灰不可点(cursor-not-allowed),悬停提示「**@角色仅图片/视频模式可用**」;图片/视频模式下提示为「**@角色(一致性引用)**」。**(手感)**

### 1.8 数量 stepper 与提交

- [ ] **1.15** **【操作】** 点 stepper 的减号(Minus)与加号(Plus)调整数量,试探下限与上限。
  **【预期】** 中间显示「**×<数字>**」(默认 ×1);减号最低到 1(再点不动),加号最高到 100(再点不动)。数量变化时估价条同步刷新为「**<数量> 条 ≈ <积分>**」。(拆解模式该 stepper 隐藏,恒为 1。)**(手感)**

- [ ] **1.16** **【操作】** 把数量 stepper 调到 **11**(> 10),或选一个会让估价 > 1000 的组合,然后点「**发送**」(或输入框按 Enter)。
  **【预期】** 弹出确认对话框,标题「**确认批量提交**」,正文形如「**将提交 <N> 个<成片类型>任务,预估消耗 <积分> 积分(当前余额 <数字>)。积分按任务在服务端逐条扣除,失败自动退款。**」;底部两个按钮「**再想想**」(取消)与「**确认提交**」。点「确认提交」才真正提交。**(手感)**
  *(阈值:count>10 或 estimated>1000 触发;正文成片类型随模式/腿变化。)*

- [ ] **1.17** **【操作】** 在任一模式填好参数与内容(数量≤10 且估价≤1000),点「**发送**」。
  **【预期】** 发送按钮为紫色含 Send 图标 + 文字「**发送**」;提交中变转圈(Loader2)。提交成功后输入框清空、数量复位为 ×1、商品卡/链接 chip 清除。主区批次流顶部插入一张新的 Batch 卡。
  *(发送禁用条件:上传中/有失败附件/校验不过/余额不足;下方可能显示「有素材上传失败,移除后可发送」(红)。)*

### 1.9 提交后 — 主区批次流 Batch 卡

- [ ] **1.18** **【操作】** 提交一批后,看主区批次流最上方新 Batch 卡卡头。
  **【预期】** 卡头左侧显示批次标题(商品模式=商品标题,其余=文案/默认名);下方一排灰色参数快照 chips:模式 chip(视频/图片/幻灯片/商品成片/爆款拆解/结构复刻之一)、模型标签 chip、比例 chip(auto 显示为「**自动比例**」)、时长「**<秒>s**」chip、分辨率 chip、@角色 chip、「**≈<积分> 积分**」chip;末尾时钟图标 + 「**MM.DD HH:MM**」创建时间。**(手感)**
  *(若有 blueprintId 还会出「蓝图」/「报告」按钮,报告仅 deconstruct。)*

- [ ] **1.19** **【操作】** 观察 Batch 卡卡头右侧进度统计区。
  **【预期】** 显示「**<已完成>/<总数>**」大号数字(如 0/12);有失败显示红色「**失败<N>**」;有进行中显示蓝色脉冲点 + 运行数字。最右一个 Trash2 图标按钮,悬停提示「**移除批次记录(不删除任务与产出)**」。(进度随后端写回刷新。)

- [ ] **1.20** **【操作】** 分别提交一批 **≤8 条**和一批 **>8 条**的任务,观察 Batch 卡内 Job 网格与卡底展开控件。
  **【预期】** ≤8 条:全部 JobCell 直接铺在网格里,卡底无展开按钮。>8 条:只显示前 8 个,卡底出现「**展开全部 <总数> 条**」按钮(ChevronDown);点开后展示全部并出现「**收起**」按钮(ChevronUp)。**(手感)**

- [ ] **1.21** **【操作】** 点 Batch 卡网格里任意一个 Job 单元格。
  **【预期】** 右栏滑出 Job 详情抽屉(JobDrawer);再点同一单元格或点抽屉关闭则收起。单元格左上角状态角标:**排队/进行中/完成/失败/已清理**(灰/蓝脉冲/绿/红/灰),入库后叠加金色「**已入库**」角标;图文帖单元格右上有「**图文×<数>**」角标;进行中底部有蓝色进度条,失败态底部显示红色错误文案。**(手感)**
  *(JobDrawer 与 BlueprintDrawer 右栏互斥。)*

- [ ] **1.22** **【操作】** 在有失败/可入库成片的 Batch 卡,看卡底右侧按钮。
  **【预期】** 有失败任务时出现「**重试失败 <N> 条**」按钮(RotateCcw);有可入库成片时出现琥珀色「**批量入库 <N> 条**」按钮(Archive,处理中转 Loader2)。点重试后 toast「**已重新排队 <N> 条任务**」;入库成功 toast「**已入库**」。(入库走 `/api/studio/library`。)

## 二、蓝图抽屉:卖点 / 台词 / hooks 矩阵 / 存为配方

> 在一条**商品来源(product_link)**的批次上打开蓝图抽屉(右栏)。门B 拆解来源的差异见第四节末尾对照。

### 2.1 头部与商品字段编辑

- [ ] **2.1** **【操作】** 在商品来源批次上打开蓝图抽屉,观察右栏头部。
  **【预期】** 头部左侧琥珀色文件图标 + 标题「**蓝图编辑**」;若来源为商品链接还显示可点的来源域名(取 URL hostname,解析失败显示「**来源链接**」);右上角关闭 X。首屏加载时中间显示「**读取蓝图…**」带转圈;读取失败显示 loadError 文案或「**蓝图读取失败**」并有「**重试**」按钮。

- [ ] **2.2** **【操作】** 在「**商品标题(钩子)**」输入框内修改标题(如清空看校验)。
  **【预期】** 分组小标题逐字「**商品标题(钩子)**」;输入框可编辑(maxLength 200),改动后底部保存按钮从「已保存」变为「**保存蓝图**」。若标题清空后点保存,弹红色 toast「**标题不能为空**」。

- [ ] **2.3** **【操作】** 在「**卖点(勾选进入成片文案,可改写)**」区,勾/取消某卖点复选框;直接在卖点输入框内改写文本。
  **【预期】** 小标题「**卖点(勾选进入成片文案,可改写)**」(ai_gen/assembly 腿的批次末尾追加「**;逐镜腿口播以下方分镜台词为准**」)。取消勾选的卖点行文字变灰并加删除线,勾选的为亮色;改动后底部按钮变「保存蓝图」。若把所有卖点都取消勾选后点保存,弹红色 toast「**至少勾选一个非空卖点**」。若存在目标人群,卖点区下方显示「**目标人群:…**」。

### 2.2 Hook 候选生成与多选(商品蓝图)

- [ ] **2.4** **【操作】** 在「**Hook 候选(勾选进入变体矩阵,逐条轮转注入首镜口播)**」区右侧点「**生成候选**」按钮。
  **【预期】** hooks 为空时按钮为「**生成候选**」(Sparkles 图标),已有时为「**重新生成**」;空态提示「**暂无候选——点「生成候选」按商品卡出 4 个类型各异的开场 hook**」。点击后按钮转圈禁用,成功弹 toast「**已生成 N 个 hook 候选,勾选后进入变体矩阵**」,列表出现候选(每条前有类型标签:**痛点/悬念/对比/场景**),各带复选框可多选。失败弹红色 toast「**hook 生成失败**」。
  *(图文帖批次此区标题改为「**Hook 候选(勾选进入变体矩阵,逐条轮转作为文案开头)**」。)*

- [ ] **2.5** **【操作】** 勾选/取消若干 hook 候选前的复选框(玫红 accent)。
  **【预期】** 可多选;每条 hook 行以类型 chip(玫红边框如「**痛点**」)+ hook 文本呈现。勾选变化会置 dirty(底部按钮变「保存蓝图」)。这些勾选构成后续变体矩阵的 hook 维度。**(手感)**

### 2.3 分镜台词编辑与保存

- [ ] **2.6** **【操作】** 在「分镜台词」区逐镜 textarea 内改写台词。
