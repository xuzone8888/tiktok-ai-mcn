# TikTok Shop Partner Center 注册申请步骤方案

整理时间：2026-03-10
来源：TikTok Shop Partner Center 官网 + Developer Guide 浏览器实测

================================================================
前置材料清单（注册前先准备好）
================================================================

  [ ] 公司营业执照 (Business License) — PDF 或清晰图片
  [ ] 公司全称 — 与营业执照一致
  [ ] 公司注册号 — 与营业执照一致
  [ ] 公司注册地址 — 与营业执照一致
  [ ] 企业负责人身份证/护照 — 清晰扫描件
  [ ] 公司 Logo — 清晰版，用于 App 信息
  [ ] 公司简介（英文）— 用于申请表单
  [ ] 邮箱（公司邮箱优先）— 用于注册账号

================================================================
Step 1: 创建 Partner Center 账号
================================================================

  网址：
    美区：https://partner.us.tiktokshop.com
    东南亚/跨境：https://partner.tiktokshop.com

  操作：点击右上角 "立即加入 / Join Now"
  注册方式：邮箱 + 密码（建议使用公司邮箱）

================================================================
Step 2: 选择开发者类型（重要！选错后续很难改）
================================================================

  ❌ 不选 Seller Developer — 只能对接自己名下的店铺
  ✅ 选择 App Developer / System Integrator (ISV)

  为什么选 App Developer？
  - ToryX 是第三方平台，要服务多个创作者
  - 只有 App Developer 才能创建 Public App，让多人授权使用
  - Seller Developer 只能做自用的 Custom App

================================================================
Step 3: 实体认证（公司信息审核）
================================================================

  注册后系统会要求提交公司信息进行人工审核：

  需要填写：
  - 公司全称（英文）
  - 公司注册号
  - 公司注册地址
  - 联系人信息

  需要上传：
  - 营业执照扫描件 (PDF/图片)
  - 企业负责人身份证/护照扫描件

  审核时间：约 1-3 个工作日

================================================================
Step 4: 创建 App 获取凭证
================================================================

  审核通过后，登录 Partner Center 控制台：

  1. 点击 "Create App"
  2. 填写 App 基本信息（名称、Logo、描述）
  3. 选择 App 类型：

     Custom App — 私有应用，最多 25 个用户，审核较快
                  建议：先做这个，用于测试

     Public App — 上架到 TikTok Shop App Store，严格审核
                  建议：测试跑通后再申请

  4. 系统生成 App Key 和 App Secret → 安全保存！

================================================================
Step 5: 申请 Affiliate Creator API 权限
================================================================

  这是实现"挂车发布"的核心步骤。

  5.1 选择业务类目
      在 App 设置中选择 API 权限类目：
      Customer Engagement > Affiliate

  5.2 申请所需 Scope

      必须申请：
      - creator.video.write      发布带货视频
      - creator.showcase.read    读取橱窗商品
      - creator.showcase.write   添加橱窗商品

      后续追加（联盟带货时）：
      - creator.affiliate_collaboration.read  搜索联盟商品
      - creator.affiliate.share_link.read     生成带货链接

  5.3 重要提醒

      ⚠️ Affiliate API 权限默认是关闭的 (Inactive)！
      注册成功后需要联系 TikTok Shop 的 Account Manager (客户经理)
      进行人工审批开通。
      可通过 Partner Center 内的"联系我们"或邮件申请。

================================================================
Step 6: 配置测试环境
================================================================

  测试店铺：Partner Center 控制台可申请 Sandbox 测试店铺
  测试创作者账号：使用你已有的 TikTok Shop 资格创作者账号
  授权测试：App 创建后可立即测试 Creator 授权流程

================================================================
关键时间线
================================================================

  Day 1      注册账号 + 提交公司信息
  Day 2-4    等待实体认证审核 (1-3 工作日)
  Day 5      审核通过 → 创建 App → 获取 App Key/Secret
  Day 5      申请 Affiliate Creator API 权限
  Day 5-10   等待 Affiliate 权限开通 + 开始对接代码

================================================================
注意事项
================================================================

  1. 美区和东南亚是两个独立的 Partner Center
     如果两个市场都要做，可能需要分别注册

  2. 英国和欧盟市场 Affiliate API 不可用

  3. App Key/Secret 和 TikTok for Developers 的 Client Key/Secret
     完全独立，不能混用

  4. 创建 Custom App 先跑通流程
     确认没问题后再转 Public App 上架

  5. 创作者必须本身已开通 TikTok Shop 资格
     美区需 1000+ 粉丝
     否则 API 会返回 permission check failed
